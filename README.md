## Usage

1. Move `dist/rose-pine.gitconfig` to `~/.config/git/themes/rose-pine.gitconfig`
2. Include the theme in your global git config, usually at
   `~/.config/git/config`:
   ```
   [include]
       path = ./themes/rose-pine.gitconfig
   ```
